# Bipsy Business · web

Web informativa de Bipsy Business, la app de gestión y reservas para negocios con cita.
Angular 18 standalone, sin backend por ahora.

```bash
npm install
npm start               # http://localhost:4200
npm run build           # dist/bipsy-business-web-app
npm run hero:manifest   # tras exportar los fotogramas de Mr. Bip a public/mr_bip/hero
```

- Contenido (funciones, planes, negocios, FAQ, blog, legales): `src/app/data/`.
- Sistema de diseño (tokens de la app de negocio): `src/styles.css` y `src/styles/app-mockup*.css`.
- Ilustraciones de Mr. Bip: `public/mr_bip/<código>.webp` (la lista de códigos está en la documentación del proyecto).
